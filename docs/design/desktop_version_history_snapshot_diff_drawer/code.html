System Architecture & Hybrid Data Engine

Inkpact operates a decentralized local-first storage runtime backed by Yjs document CRDTs on clients and durable persistence in PostgreSQL on the Unraid home cluster.

Sync Pipeline & CRDT Guarantees Section 4.2

All peer mutation vectors sync over WebSockets to an intermediary ASP.NET Core minimal API backend. Documents reside continuously in-memory on the application tier.

remove_circle_outline DELETED IN CURRENT HEAD

- Direct synchronous database writes are queued per keystroke directly onto `document_deltas` with full historical JSON logs unpruned.

- Memory footprint is unconstrained; clients pull raw transaction histories spanning all initial session timestamps without state vector boundaries.

Clients maintain full write autonomy while disconnected from LAN nodes, reconciling via Lamport scalar clocks.

Vault Durability & Snapshot Strategy

Vault documents are committed into SQLite cache stores locally on desktop clients and mirrored onto Postgres arrays through idempotent binary update streams.
