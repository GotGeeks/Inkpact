Local-First Immutable Guarantee: Inkpact uses Yjs binary update vectors streamed over secure WebSockets. Even in an offline state, clients edit the in-memory document state locally, syncing diffs instantaneously upon reconnecting to the Unraid node.

Sync Pipeline & CRDT Guarantees

add drag_indicator

The sync pipeline executes within an ASP.NET Core minimal API WebSocket hub running on Kestrel. Incoming binary updates are verified for cryptographic signature before being pushed down to other connected peers. Concurrently, updates append sequentially into the local page_updates table.

add drag_indicator

To prevent state divergence, a background compaction worker periodically aggregates individual delta rows into a single compacted Yjs document state blob Maria which ensures query latency scales logarithmically rather than linearly with edits.
